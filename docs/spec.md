# 学習ループ 仕様（2026-09-11 時点）

中学1年生の定期テスト対策を、親が1日5分＋土曜1時間で回す Web アプリ。
`index.html` 1ファイル（React 18 + Babel standalone を CDN から読む）。GitHub Pages（https://yuuki-lgtm.github.io/gakusyu/）に置き、iPhone のホーム画面から使う。

この文書は「いまの状態」だけを書く。経緯と理由は最後の「決めたことと理由」に集約する。コードの細部と開発の作法は `CLAUDE.md`。

---

## 1. 設計思想（変えない）
1. **未定着リストが軸。** 点数ではなく「まだ身についていない項目」を管理する。
2. **定着の判定は白紙再生のみ。** ノートが埋まった、ワークを解いた、は証拠にならない。例外は「類題が作れなかった回」だけ（元の問題をもう一度解かせ、「解けた」では間隔を据え置き、「説明もできた」でのみ進める）。
3. **初見と再テストを区別。** 学力の推移は初見だけで測る。
4. **項目は消えない。** 正解で間隔が伸びる（1→3→7→14→30日）。落とせば1日に戻る。30日の段階で正解したら「安定」。安定は日々の紙から外れ、月1の累積テストにだけ混ざる。落とせば戻る。
5. **「解けた」だけでは7日から先に進まない。** 「説明もできた」で長い間隔へ。用語・暗記もの・「説明不要」の項目は除く。
6. **3回落ちたら反復をやめて診断。** 前提の単元に戻る。
7. **親は開始の声かけ・採点・確定だけ。** 横で見張らない、教えない。
8. **子どもが先に判定し、親が確定。** 一致率が「採点を子どもに渡す時期」の目安。
9. **紙でやらせる。** 画面を見せながら解かせない。問題は PDF で印刷。
10. **作れない形式（図・資料・長文・記述）も測る。** リスニングは未定着に入れず、形式の成績として記録するだけ。

## 2. 1週間の流れ
- **学期の初め（1回）**: 「教材→取り込み」でワークと教科書をスキャンして入れる。「教材→単元と進度」で目次を撮って単元とページ範囲を登録し、習ったところまで「ここまで」。「その他→設定」で Supabase と API キー。
- **平日・子ども**: 机の紙（類題）を解く → 解答を見て各問題の右の欄に自分で ○ か × → 学校のワーク。
- **平日・親（夜5分）**: 「今日」に出る順に押す。昨日の紙を採点（間違えた行に ✓ を入れて確定）→ 次の紙を作る（類題を作って PDF）→ ワークの×を登録（ページで×をタップ）→ 今日の最後のページ（教科ごとに「p.N まで」）。順番は並びで示すだけで、強制しない。
- **土曜**: 「紙→5教科テスト」で作って印刷 → 解く → 赤ペンで採点 → 用紙の行の「この用紙の答案を撮る」で結果と未定着を自動登録。
- **日曜**: 「紙→読解・記述」で1本ずつ。
- **定期テスト前（14日前から）**: 「今日」に「模試を作る」が出る。「紙→模試」で作って印刷、50分で解かせ、採点して用紙の行で撮る。14・7・3日前の3回。範囲外の項目はテスト翌日まで後ろ倒し。
- **返却時**: 「教材→取り込み」で答案を「テスト」として取り込み、「未定着→×を登録」で×をタップ。「教材→定期テスト」に実点を入れる。
- **週1**: 「その他→相談用の依頼文」をコピーして相談。

## 3. 画面

### 3.1 下のバー（5つ。扱うもの＝名詞で分ける）
| タブ | 中身 |
|---|---|
| **今日** | やることだけ。先頭1つを大きく、残りを「そのあと」に3行まで、残りは「ほか N 件を見る」 |
| **紙** | 採点待ち／次の紙／5教科テスト／模試／読解・記述 |
| **未定着** | 一覧（先頭に件数と教科の帯）／×を登録 |
| **教材** | 取り込み／単元と進度／定期テスト |
| **その他** | 分析／相談用の依頼文／設定／使い方／最新版に更新 |

- 一度開いたタブは裏に残す。バーで戻っても切り替え・入力途中・スクロール位置がそのまま。バーは各グループで最後に開いていた画面に戻し、同じグループをもう一度押すと先頭へ。
- スクロールは body ではなく `.root` の中で行う（iOS の端の跳ね返りでバーの下に地が見えないため）。
- 画面の中のモード切り替えは下線のタブ。種別や教科の選択は枠つきのセグメント。丸いチップは完全な半円。入力欄は 14px・高さ 40px。
- 各画面冒頭の説明は初回だけ開き、以後は右上の「?」で開閉（既読は端末に記憶）。

### 3.2 右下の +（紙を入れる）
5つのタブの第一階層に出る。押すと先にカメラ／写真／ファイルの選択（写真も PDF も）。選ぶと下から半透明の墨色のシートが上がり、縮小と枚数（丸い＋で追加で撮れる）の下に4択:
テストの答案→用紙を選んで採点する／教材→取り込む／目次→単元を登録する。PDF は教材だけ。
ファイルは行き先の画面が開いた時に受け取る（用紙は開いた時に読み取り、取り込みは読み込み済みで開く、単元は教科と種類を選んでから読み取り）。新しい処理は持たない。

### 3.3 今日
`nextActions(d)` の順: 単元未登録 → 進度未設定 → 昨日の紙を採点（採点待ちがあるとき）→ 次の紙を作る（候補があるとき）→ 今日のワークの×を登録（教材があり今日まだ登録していない）→ 今日の最後のページ（ワーク・教科書があり今日まだ入れていない）→ 未採点の答案 → 模試を作る → 最初の項目 → 週末の進度更新と作問 → 累積テストを作る（前回から30日）→ 3回落ちた項目の診断 → バックアップを書き出す（前回から30日）。
黒いカード（いまやること）と白い行（そのあと）はカード全体が押せる。要約や件数は置かない。下に「使い方を見る」。

### 3.4 紙
- **採点待ち**: 印刷済みの項目を、紙ごとに、印刷したときの問番号の順に並べる（番号は印刷時に項目に控える。同じ日に2回印刷すれば別の紙として「（2枚目）」の見出し。教科では分けない）。行の先頭に問番号（「問3〜5」）、教科・単元・形式。項目名の下に紙に出た問題を1行ずつ（紙の問番号＋本文の先頭）。判定は人が入れる: 各行に「できなかった」のチェック、説明の問いがある項目には「説明もできた」のチェック。✓ の無い行は「まとめて確定」で「解けた」。「できなかった」は誤答の種類（4択）が必須。「問題が変」は判定せず次の紙で作り直す。「やっていない」「全部を次の紙に戻す」で印刷前に戻せる。行をタップで類題と解答、考え方、3回落ちていれば診断（手順を項目として登録できる）。最後に「次は次の紙を作る →」。下に「採点待ちの分をもう一度PDFにする」（作り直さない）。
- **次の紙**: 候補＝期日が明日までに来る未印刷の項目。先頭に「候補に入っていない件数と理由」と、後ろ倒し中なら橙の枠。優先順: 定期の範囲内 → 再出題・再挑戦（期日が古い順）→ 新しく登録 → 落とした回数。各行に印: 再出題（N日あけて・前回 ○）／再挑戦（前回 ×）／新しく登録、遅れの日数。上から上限（既定 18 問。設定で変更）まで自動でチェック、残りは繰り越し。教科ごとの見出し。「次の紙を作る（N件 → PDF）」で類題を生成（今日作った類題は再利用。「作り直す」で新しく）。最後に「次はワークの×を登録する →」。
- **5教科テスト**: 教科を選んで作る（週次／累積）。教材ページを添付して作問し、参照した図だけ資料に印刷。「N教科のテストを作る」→「1つのPDFに」。用紙の行を開くと「この用紙の答案を撮る」。下に「ワークの結果を記録」（形式別の成績の手入力）。
- **模試**: 「教材→定期テスト」で範囲を選んだ直近のテストの範囲で、本番と同じ形式（大問・配点・50分・100点）。未登録なら「定期テストを登録する」ボタン。
- **読解・記述**: 読解は新規の文章と設問、記述は課題と添削。

### 3.5 未定着
- **一覧**: 先頭に「未定着 N件」と教科の色で分けた横幅 100% の帯と凡例。仮の項目があれば「仮の項目 N 件に名前を付ける（AI）」。教科ごとに項目: 名前（「仮」の印）、どういう問題だったか（AI の要約）、いつの紙に出るか（次の紙に出る／MM-DD の紙に出る／採点待ち／定期テスト後／安定）、単元・形式・回数・間隔、誤答の種類のチップ（タップで4択）、教科を直す、説明あり／説明不要の切り替え、削除（×の直後に「取り消す」を6秒）。
- **×を登録**: 教科 → 教材（種別が1つなら押せない表示）→ ページを開いて×だった問題をタップ。青い小さな印。印のそばのポップオーバーで誤答の種類（初期値「知らなかった」）と「この印を消す」。登録済みの印は薄く、タップで状態と変更。「N件を未定着に入れる」で登録し、AI が印の位置を読んで項目名・要約・形式・暗記ものかを付ける（失敗した分は次回起動時に自動で付け直す）。下に「今日の最後のページ」（教科・教材ごとに「p.N まで」）。教材が無い教科は「手で1つ追加」だけ。

### 3.6 教材
- **取り込み**: まず PDF か画像を選ぶ → 枚数と見開きの判定 → 教科（既定なし。選ぶまで保存できない）・種別（ワーク／教科書／テスト。テストは問題用紙／答案／同じ紙）・綴じ方向（横書き／縦書き）・最初の番号（自動で続き番号）→ 保存。横長は見開きとして綴じ目で2ページに切る。下に「取り込み済み」（教科を選ぶと種別ごとの一覧と削除）。
- **単元と進度**: 教科書／ワークの目次を撮って単元とページ範囲を登録、または手で追加。「ここまで」で進度。ワークの×を登録したページからも自動で進む。
- **定期テスト**: 日付・名前・出題範囲（単元）。範囲内の未定着、未出題の単元、手つかずのページ、実点と予測。

### 3.7 その他
分析（保持率・形式別・一致率・誤答の種類・実施ログ）／相談用の依頼文／設定（同期の設定と別端末へのリンク、API キー、今日の分の上限、バックアップ）／使い方（初めての人向け）／最新版に更新（バージョン付き）。

### 3.8 通知と帯
- スナックバー: 画面上部から降りて上へ消える。成功（緑・✓）と入力の不備（橙・!）は 4.5 秒、エラー（赤・ⓧ）は × を押すまで。
- 使えない状態（API キー未設定／無効／残高切れ）は、ヘッダーの下の帯に全画面で出し続け、直れば消える。

## 4. 紙の仕組み（核）
- **期日と間隔**: 判定のあとの再出題日だけが日付を持つ。正解→3日後→7日→14日→30日（説明もできた、で先へ）。落とす→翌日。30日の段階で正解→安定。
- **登録した項目**: 日付を持たず「次の紙」の候補。何件登録しても候補に並び、上限までがその紙、残りは繰り越し。
- **定期テスト前**: 14日前から範囲外の項目をテスト翌日まで後ろ倒し（間隔は保つ）。
- **類題**: 元の問題の画像を渡して生成。習得中（1・3日）は3問、保持の確認（7日以上）は1問、暗記ものは1問。数学・理科の計算と英語の文法・英作文は検算し、不一致なら作り直す。作れなければ元の問題を切り出して載せる。
- **考え方と例題**: 2回以上落ちた、または「知らなかった」の項目に付ける。載せるのは初回と再挑戦の回だけ。再出題の回には載せない。
- **紙の形**: 各問題の右端に 15mm 角の ○× の欄。上部に1行の注意書き。教科が複数なら見出しは「今日の紙」、点の欄は無し。問題を先に、白紙で偶数に揃え、解答は最後にまとめる（両面印刷で解答が別の紙になる）。
- **判定**: 親が採点待ちの画面で、間違えた項目に「できなかった」の ✓（出した問題が1つでも × なら）。説明の問いにも答えられていれば「説明もできた」の ✓。✓ の無い行は「解けた」。AI で ○× は読まない。

## 5. データ
- 1つの JSON（`gakushu_loop_v3`）を localStorage と Supabase の1行に保存。配列ごとに id と更新日時で統合、削除は墓標。
- 教材のページ画像は Supabase Storage の非公開バケット。端末には索引だけ。
- 項目: 教科・単元・名前・要約・形式・誤答の種類・履歴・段階・落とした回数・期日・状態・類題・印刷日・タップ位置・後ろ倒し・説明不要・考え方。
- 用紙: 種別（週次／累積／模試／読解）・問題・参照した教材ページ・状態。
- 詳細は `CLAUDE.md` の「データ構造」。

## 6. AI
- Anthropic API を直接呼ぶ。類題・答案の読み取り・目次・項目名は Sonnet 5、診断・同じ技能の判定・模試は Opus 5。失敗時は Sonnet 5 で1回やり直す。
- 出力は JSON 指定。エラーは日本語にして出す。
- 教科書や既存作品の文章は複製しない。教材ページは用語・難易度を合わせるためと図の参照のために渡す。

## 7. 決めたことと理由（経緯）
- 下のバーは「やること」ではなく「扱うもの」で分ける（OOUI）。作った本人が迷ったのは、タスクの一覧と状態の要約が同じ画面に混ざっていたため。戻す可能性はある。
- 夜の作業の4段階ウィザードは廃止。足場のほうが目立ち遠回りだった。今日の画面が状態のある行を出し、順番は並びで示すだけ。
- 登録した項目に「翌日」の期日を付けるのをやめた。日付の概念は判定のあとだけ。多数登録時の分散も廃止（上限と繰り越しで量は守れる。項目が見えなくなり「なぜ出ない」を生んだ）。
- 紙の判定は4択のチェック欄から ○× の欄へ。子どもに毎日4択を読ませるのは重く、決まった位置の ○× のほうが読み取りも確実。
- 採点画面の「子ども」の行はボタンを持たない。紙から読んだ値の表示だけ。
- 考え方と例題は再出題の回に載せない。白紙再生を確かめる回だから。
- 取り込みは「読み込んでから教科・種別」。教科の既定を無くした（数学のまま理科を入れる事故）。
- 印の色は青。赤だと答案の赤ペンと混同され、印の無い問題まで拾われた。印は小さく（幅の 0.7%）、以前の大きな丸は隣の問題にかぶった。
- ラベルは名詞で「何を作る・何を見るか」が分かる形に。「作る」「印刷」「定期」のような略語は避ける。
- 「いまやること」は黒塗りのカード。白いカード＋縦線は試して戻した。
- 配色は元の緑がかった灰。白ベースは試して戻した。
- 模試は1回きりで再利用しない。×は未定着へ、点は定期の予測にだけ。
- 定期テスト前の後ろ倒しは期日だけ動かし段階は保つ。
- 教材画像は Storage に置く（localStorage の 5MB を超えないため）。参照した図だけ印刷する（毎回16ページは続かない）。
- 見開きは自動判定して綴じ目で切る。×の登録はタップ式で索引に依存しない。
- 類題は元の問題と同じ型で中身（数値・語句・場面）だけ変える。型まで変えると子どもには別の問題に見えて解けない（2026-09-11）。
- 採点は人が ✓ を入れる（AI で紙の ○× を読まない）: 読み取りは返答が空や途中切れで止まり、直す手間のほうが大きかった。間違えた行だけ ✓ なら1紙あたり数タップ。採点待ちの並びも教科別から紙の問番号順に（2026-09-11）。

## 8. やらないこと
- 通知、ゲーミフィケーション、子ども向けダッシュボード、画面上での出題。
- ピンチ拡大。白ベースの配色。
- 機能を足す前に「続くか」を問う。迷ったら足さない。
